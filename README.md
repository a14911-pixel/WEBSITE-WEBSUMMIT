# 🌐 Microsite Web Summit 2026

## 📌 Sobre o Projeto

Este projeto consiste na criação de um microsite inspirado no Web Summit 2026, um evento internacional de tecnologia, inovação e empreendedorismo, realizado em Lisboa.

O objetivo é desenvolver um website moderno, funcional e adaptado a computadores, tablets e telemóveis.

## 🛠️ Tecnologias Utilizadas

- HTML5 – Estrutura das páginas.
- CSS3 – Design e estilos.
- CSS Grid e Flexbox – Organização dos elementos.
- Visual Studio Code – Editor de código.

## 📂 Estrutura do Projeto

```text
microsite-websummit/
│
├── index.html
├── programa.html
├── oradores.html
├── contacto.html
├── README.md
│
├── css/
│   └── style.css
│
├── images/
│
└── media/
```

## 📄 Páginas do Website

- **Início:** Apresentação do evento, data e localização.
- **Programa:** Horários e sessões do evento.
- **Oradores:** Fotografias e informações dos convidados.
- **Inscrição/Contacto:** Formulário de inscrição com validação HTML5.

## ⚙️ Funcionalidades

- Navegação entre as quatro páginas.
- Design responsivo.
- Apresentação do programa e dos oradores.
- Formulário de inscrição.
- Utilização de imagens e vídeos.

## 🚀 Como Executar

1. Abrir a pasta do projeto no Visual Studio Code.
2. Abrir o ficheiro `index.html` num navegador.
3. Opcionalmente, utilizar a extensão Live Server.
